AME-CHAN MINI — первая локальная заготовка

Что внутри:
- index.html — интерфейс и логика;
- sprites/ — GIF и PNG из предоставленного архива.

Как посмотреть:
1. Распакуйте архив.
2. Откройте index.html в браузере на компьютере.
3. Для iPhone/Safari надёжнее разместить папку на статическом хостинге (например, GitHub Pages или Cloudflare Pages), либо использовать локальный сервер/приложение, умеющее отдавать HTML и соседнюю папку sprites.

Все реакции пока используют случайные GIF, потому что исходные имена IMG_#### не описывают эмоции. Следующий шаг — вручную сопоставить GIF с нужными состояниями и сделать более точные реакции.

Это прототип без внешних API, нейросети и платных токенов.
